About Mini Arcade

A CS50 Final Project exploring full-stack web development and game algorithms.

🎯 Project Overview

Mini Arcade is a web gaming hub featuring four classic games: Tic-Tac-Toe, Connect 4, Rock-Paper-Scissors (with Lizard-Spock), and a 52-card Playing Cards Suite (High-Low & Blackjack).

The project was built for CS50: Introduction to Computer Science to demonstrate full-stack fundamentals: writing clean backend routes and game logic in Python with Flask, designing responsive templates with Jinja2 and HTML/CSS, and creating interactive game boards using client-side JavaScript that communicate with the server via the Fetch API.

🛠️ Technologies Used

🐍

Python & Flask

Handles server routing, session state management, AI move computation, and win/tie validation.

🌐

HTML5 & Jinja2

Semantic page structures with template inheritance (layout.html) for a DRY, modular codebase.

🎨

Modern CSS

Custom arcade theme featuring CSS grid, flexbox layouts, glowing status banners, and mobile responsiveness.

⚡

Vanilla JavaScript

Event-driven DOM updates, asynchronous fetch() requests, and dynamic board rendering with zero heavy frameworks.

🧠 Key Algorithms & Game Mechanics

  • Minimax Algorithm (Tic-Tac-Toe): The unbeatable AI uses recursive minimax tree evaluation with depth discounting, maximizing the computer's score while minimizing the player's potential outcomes.
  • Grid Gravity & 4-Directional Scan (Connect 4): Discs fall to the lowest empty slot in a 6x7 matrix. Win detection checks horizontal, vertical, and both diagonal slopes using vector offsets.
  • Cyclic Graph Evaluation (Rock-Paper-Scissors-Lizard-Spock): Evaluates win conditions using a rule dictionary that maps each hand gesture to the two gestures it defeats, returning detailed pedagogical explanations.
  • Fisher-Yates Deck Shuffling & Dynamic Ace Scoring (Cards): Cards are shuffled using Python's random distribution. The Blackjack engine dynamically adjusts Ace values from 11 to 1 whenever a hand exceeds 21.
